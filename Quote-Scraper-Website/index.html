Quote-Scraper: the specimen case

Every quote is a specimen. The scraper gathers them from quotes.toscrape.com, pins each new one into the collection as a row of its own, and the case keeps growing, five minutes at a time.

What the scraper does

Quote-Scraper collects quotes from http://quotes.toscrape.com and exports them to quotes.csv. On each run, Quote-Scraper.py fetches the site's front page, reads the quote blocks on it with BeautifulSoup, chooses one quote at random, prints it, and appends it to the csv as a single row: the quote text, a dash, and the author.

one quote per run, pinned in its own row

The five minute cycle

The collection is kept by a GitHub Actions workflow, not by hand. The workflow (named Daily Script, whatever the name suggests) runs on a cron of */5 * * * *, every five minutes:

  • It sets up Python 3.8 and installs the dependencies: requests from requirements.txt, and BeautifulSoup4 alongside it.
  • It runs python Quote-Scraper.py, which adds one more row to quotes.csv.
  • It commits the result with the message "Update quote csv data" and pushes.

A second, quieter workflow opens a check-in issue every seven days, asking what errors the project has met that week.

The warning on the case

The case was not seeded by hand and needs no seeding: Quote-Scraper.py never reads quotes.csv back. It opens the file in append mode, which creates it if it is missing, and there is no verification step and no duplicate check anywhere in the script. That is how the case grew so deep, because a quote already pinned on an earlier run can be pinned again, and most have been.

The collection so far

quotes.csv

The dataset itself: 13,479,531 bytes and 118,892 rows when this page was built, one quote per row, gathered five minutes at a time.

Quote-Scraper.py

The whole scraper in one small file: fetch, parse, choose at random, print, append. It imports requests, BeautifulSoup, csv, and random, and nothing else.

requirements.txt

One line: requests. BeautifulSoup4 is installed by the workflow next to it.
